# ArtaGames · Giochi da Tavolo 1vs1

Piattaforma web minimale per giochi da tavolo classici 1vs1 pensata per **smartphone, tablet e computer**, ideale per bambini dai 5 ai 7 anni+ e per tutta la famiglia. Funziona al **100% offline (PWA)** senza server o costi di gestione.

---

## 🎲 Giochi Inclusi

1. **Forza 4 (5+ anni)**: Allinea 4 gettoni con caduta gravitazionale realistica.
2. **Dama Classica (6+ anni)**: Scacchiera 8x8 con salti, catture multiple e incoronazione delle Dame.
3. **Go Semplificato (6+ anni)**: Mini-Goban 9x9 con cattura delle pietre, calcolo dei respiri e indicatore visivo di pericolo Atari.
4. **Battaglia Navale (6+ anni)**: Radar 8x8, disposizione navi automatica con 1 click, colpi in acqua ed esplosioni sonore.
5. **Scacchi Junior (7+ anni)**: Mosse guidate con puntini luminosi sulle caselle accessibili, allerta Scacco e vittoria alla cattura del Re.
6. **Tris Classico (5+ anni)**: Griglia 3x3 per partite lampo tra i più piccoli.

---

## ✨ Funzionalità Speciali

* **🛡️ Blocco Gesti Swipe Anti-Uscita**: Disabilita swipe laterali (gesture back/forward del browser), pull-to-refresh e pinch-zoom accidentali durante le partite.
* **👁️ Schermo Sempre Acceso (WakeLock)**: Impedisce che il tablet o telefono vada in standby durante i turni di riflessione.
* **📱 PWA & 100% Offline**: Installabile sulla schermata Home come una vera app nativa a schermo intero. Funziona ovunque, anche senza connessione internet.
* **🤖 Livelli BOT Scalabili**:
  * 🌱 **Cucciolo (5-6 anni)**: Rilassato e divertente.
  * ⭐ **Campione (6-7 anni)**: Equilibrato.
  * 👑 **Maestro (8+ anni / Genitori)**: Tattico e strategico.
* **👥 Modalità 1vs1 Locale (Pass & Play)** con rotazione del tavolo a 180° per giocare faccia a faccia.
* **🎨 5 Temi Grafici Centralizzati**: Zen Wood (Legno Kaya), Nordic Slate, Midnight OLED, Emerald Club, Carta Washi.
* **🔊 Audio Sintetizzato in Tempo Reale**: Usa la Web Audio API del browser senza caricare file esterni pesanti.

---

## 🚀 Sviluppo Locale

```bash
# Installa le dipendenze
npm install

# Avvia il server di sviluppo locale su http://localhost:3000
npm run dev

# Compila la build di produzione
npm run build
```
